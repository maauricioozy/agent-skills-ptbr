# Segurança

Não publique credenciais, tokens, dados de clientes, caminhos privados ou conteúdo confidencial em issues e pull requests.

Para relatar uma vulnerabilidade, use o recurso privado **Security > Report a vulnerability** do repositório. Se esse recurso não estiver disponível, abra uma issue sem detalhes sensíveis solicitando um canal privado.

Não há programa de recompensa financeira associado a este projeto.
